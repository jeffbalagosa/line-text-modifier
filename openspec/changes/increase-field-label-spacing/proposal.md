## Why

The field labels are too close to their fields. Start by adding 5 px to the existing label-to-field spacing.

## What Changes

- Increase the visible gap between labels and their associated text inputs and textareas by 5 px relative to the current spacing.

## Capabilities

### New Capabilities

- `field-label-spacing`: Define the visible spacing between field labels and their associated text inputs and textareas, with a 5 px increase over the current spacing.

### Modified Capabilities

None.

## Impact

- Affects field-label layout styles in `index.html` for Input Text, Prepend to Each Line, Append to Each Line, Replace Word Gaps With, and Output Text.
